# 公共工程監造 CMIS

## Overview

將正式依據轉成可追溯、可直接辦理的本機監造文書結構。契約、圖說、核定計畫、機關規定與使用者範本是唯一內容依據；未提供依據就不推估、不補寫。

## 先確認依據與範圍

1. 盤點輸入檔的名稱、版次、日期、完整頁數／圖號與授權用途。
2. 建立或更新 `00_原始依據_唯讀`，保留原始檔；不得覆寫、刪除或以摘錄取代原檔。
3. 從契約、標單、圖說、監造計畫及已核定文件列出「有明確依據」的任務、表單與頻率。每項都記錄來源檔、頁碼／圖號、版次與條文／章節。
4. 依使用者指定的任務建立資料夾；未指定且無可核對依據時，先列出缺少資料，不建立表單或內容。

使用者說「全部」、「以後會用到」或「照一般監造建立」時，不把它解讀為具體任務或表單授權。先完成依據對照：每一項文件、表單與子夾必須對應一筆已提供的條文、圖號、計畫章節或範本；無對應者不命名、不建立、不列入建議。

### 資料不足時的停止條件

缺少契約、圖說、核定計畫或指定範本中的任一必要依據時，不建立暫擬資料夾、通用骨架、空白表單、待填文件、提醒或檢查清單。回覆只能包含：缺少的正式依據、取得後將依哪一條文／頁面執行、以及「未建立任何檔案」。工期緊急、工地主任要求或「先做再補」都不是例外。

## 資料夾與檔名

以任務名稱為主，不預先生成未要求的文件。任務資料夾只建立必要子夾：

- `01_依據_圖說與規範頁`
- `02_表單範本`
- `03_編寫中`
- `04_送審版`
- `05_核定版`
- `06_紀錄與回覆`

檔名使用：`YYYYMMDD_工項或任務_文件類型_位置或範圍_版次或文號.副檔名`。只有來源可證實的日期、位置、版次、文號才可填入。

## 擷取、表單與編寫

| 工作 | 必須做 | 不可做 |
|---|---|---|
| 圖說／計畫摘錄 | 擷取完整相關頁面；在檔名或索引保留來源、頁碼／圖號、版次 | 只摘文字、移除來源、混接不同版次 |
| 表單 | 僅使用契約／計畫指定或使用者提供的範本，並標示其精確來源 | 因「一般實務」自建、補齊、美化、暫擬或列出通用表單名稱 |
| 編寫 | 僅填使用者提供且可由依據驗證的資料 | 猜測規格、日期、責任、簽核、檢驗頻率或結論 |
| 範本套用 | 保留欄位、版面、字型、段落、表格、頁首頁尾 | 自行增欄、刪欄、重排或改寫未要求內容 |

需要處理 PDF、Word 或 Excel 時，先使用對應的 `pdf`、`documents` 或 `spreadsheets` 技能；任何編輯前先檢查原檔與範本格式。

## 頻率與提醒

從契約工期、核定進度、會議頻率、送審期限及計畫條文判定：一次性、施工前、每日、每週、每月、工項發生時、送審前、驗收前。未取得觸發日期或條文時，只列「待確認」，不得擅自建立提醒。

## 交付前檢查

確認每份摘錄可開啟、頁面完整、來源可回溯、放置位置正確；確認未建立無依據的表單或未授權的排版變更。回報新增／調整位置、驗證結果與待確認依據。

## 例子

使用者指定「鋼筋工程自主檢查」時，先在管制總表、契約、圖說與計畫找出此工項的要求；只建立其資料夾與可證實相關的頁面摘錄。若沒有指定表單範本或條文，就回報缺少依據，不產生自主檢查表。

## 常見錯誤

「先建通用表單再補資料」、「先建可開工的空白骨架」、「為了好看重排範本」、「為了快速省略頁碼／圖號」都違反本技能。停止該動作，改為提出缺少的正式依據或使用者決定。
