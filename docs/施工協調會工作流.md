# 施工協調會資料準備工作流

1. 讀取使用者最後確認的會議報告及管制總表，不用舊腳本覆寫。
2. 確認會次、日期、時刻與地點；未提供者留白。
3. 保留上週、本週及下週三欄，每週星期一至星期日。
4. 依日誌及使用者敘述填施工項目，條列編號，區分實績與預定。
5. 更新工期與進度；進度採相同基準及截止日，估驗比例與施工進度分開。
6. 更新提報文件、查驗、當期風險、職安宣導、缺失及待辦釋疑。
7. 更新分項施工計畫送審、材料設備送審及材料設備檢試驗三張總表。
8. 預定日期依網圖與契約推算；數量查正式標單，不把契約量填成實際進場量。
9. 會議報告在前、三張管制表在後合併，原格式保留，不另加封面或多餘說明。
10. 檢查實際可列印框線、合併格及續表，不把Word輔助格線當成框線。
11. 更新頁碼，輸出PDF逐頁檢視，排除孤頁與意外空白頁。
12. 每次會議依序編次，同次修訂版本遞增，原檔與舊版保留。
