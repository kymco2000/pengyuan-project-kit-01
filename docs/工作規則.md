# 公共工程文件工作規則

## 來源

契約及補充規定控制程序與期限；正式標單控制計價項目及數量；圖說控制材料與施工細節；施工規範補充圖說；核定計畫控制執行流程。文件衝突列疑義，不自行擇一或用案例補值。

正式用印標單與空白招標標單可能不同，不能只讀可搜尋的空白PDF。掃描原件應逐頁讀圖。

本案已由使用者排除的舊監造計畫，不再作為後續分項工程、材料、品質標準或檢試驗依據；歷史檔僅保留，不因已打包而恢復適用。

## 文件

保留原檔、指定表式、簽章及頁面幾何。Word可編輯表格不以整頁圖片冒充。合併文件須檢查分節、樣式、框線、頁首頁尾、圖表與頁碼。

八項分項工程分類為假設、拆除、擋土支撐、護坡、卵石籠、鋼筋、模板及混凝土。分類不表示各項都已完成或核定。

## 日期及狀態

預定日期依最新施工網圖及分項工序倒排；契約期限與內部推估天數分開。實際施工、進場、送審、核定、取樣及試驗結果依原始紀錄填列。缺資料留白；不得填造合格或無缺失。

## 安全與交付

只按本次授權範圍修改，保留舊版。不得移植他案人員、材料、地點、頻率或試驗數值。正式文件避免編修說明與不必要文字。收工記錄完成、待確認及限制，不自動對外送件。
