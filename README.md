# 鵬園工程工作懶人包

這是私人儲存庫中的去識別工作包。完整工程原件及歷次成果僅保存在本機完整專案包，不在此儲存庫內。

## 開始使用

1. 先讀 `docs/工作規則.md` 與 `docs/施工協調會工作流.md`。
2. 在本機準備契約、正式用印標單、圖說、施工規範及核定計畫，依來源填表。
3. `skills/` 是本案相關的自訂技能副本；平台內建文件、PDF及試算表技能須由原平台另行提供。
4. `templates/` 是去識別欄位骨架，不是核定表單，也不取代本案指定Word。
5. 先備份，依序進版，輸出PDF檢查，不直接覆寫使用者修改。

## 收錄範圍

- 三大計畫書與八項分項工程的作業規則。
- 施工協調會工作流、版本管理及資料來源規則。
- 計畫送審、材料送審及材料檢試驗的空白欄位。
- 自訂公共工程、模板與Word排版技能。
- 成果類別索引及資料核對清單。

## 不上傳的資料

契約原件、標單金額與數量明細、設計圖、營區位置與管制資料、核定計畫原件、日誌實績、人員名冊、證照、電話、簽章、保密切結、完整聊天紀錄及完整專案壓縮檔均不在本儲存庫。

## 使用限制

技能是工作指引，不是專業資格或簽證。既有腳本與舊成果不可直接套用；所有數量、規格、日期、頻率、核章及核定狀態仍須回查該工程正式文件。不得把預估日期當成實際紀錄。
